# Изменения AI-моделей: Claude → Qwen

**Дата:** 05.03.2026  
**Причина:** Оптимизация затрат на ИИ-обработку при сохранении высокого качества.

---

## 📊 Сравнение моделей

| Характеристика | Claude Sonnet 4 | Qwen 2.5 72B | Экономия |
|----------------|-----------------|--------------|----------|
| **Входные токены** | $3.00 / 1M | $0.35 / 1M | **88%** |
| **Выходные токены** | $15.00 / 1M | $0.40 / 1M | **97%** |
| **Контекст** | 200K | 128K | -36% |
| **Качество (MMLU)** | ~85% | ~82% | -3% |

### Быстрая модель (классификация, валидация)

| Характеристика | Claude Haiku | Qwen 2.5 Coder 32B | Экономия |
|----------------|--------------|---------------------|----------|
| **Входные токены** | $0.25 / 1M | $0.18 / 1M | **28%** |
| **Выходные токены** | $1.25 / 1M | $0.22 / 1M | **82%** |

## 🔧 Изменённые файлы

### 1. `backend/app/core/config.py`
```python
# Было:
OPENROUTER_DEFAULT_MODEL = "anthropic/claude-sonnet-4-20250514"
OPENROUTER_FAST_MODEL = "anthropic/claude-haiku-3"

# Стало:
OPENROUTER_DEFAULT_MODEL = "qwen/qwen-2.5-72b-instruct"
OPENROUTER_FAST_MODEL = "qwen/qwen-2.5-coder-32b-instruct"
```

### 2. `backend/app/services/openrouter_client.py`
- Обновлён словарь `AI_MODELS` с новыми моделями
- Обновлены цены в `_estimate_cost()`:
  - `qwen/qwen-2.5-72b-instruct`: (0.35, 0.40)
  - `qwen/qwen-2.5-coder-32b-instruct`: (0.18, 0.22)

### 3. Комментарии в сервисах
- `ocr_service.py` — обновлены комментарии
- `classifier_service.py` — обновлены комментарии
- `file_processing_tasks.py` — обновлены комментарии
- `prompts/operation_classifier.py` — обновлены комментарии

## 🎯 Распределение моделей по задачам

| Задача | Модель | Причина |
|--------|--------|---------|
| **AI-агент (логика)** | Qwen 2.5 72B | Мощная, хорошее рассуждение |
| **Распознавание документов** | Qwen 2.5 72B | Vision capabilities |
| **Классификация операций** | Qwen 2.5 Coder 32B | Быстро, дёшево, достаточно точно |
| **Налоговые вопросы** | Qwen 2.5 72B | Требует точности |
| **Валидация данных** | Qwen 2.5 Coder 32B | Простая задача |
