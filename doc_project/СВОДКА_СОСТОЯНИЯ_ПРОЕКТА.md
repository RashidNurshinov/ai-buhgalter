## 1. Общая архитектура

```
┌─────────────────────────────────────────────────────────────┐
│                        Nginx :80                            │
│   /api/* → backend:8000    /* → frontend:3000               │
├─────────────────────────────────────────────────────────────┤
│  Frontend (React 19 + Vite + TypeScript + Ant Design)       │
│  Port 3000                                                  │
├─────────────────────────────────────────────────────────────┤
│  Backend (FastAPI + SQLAlchemy 2.0 async + Alembic)         │
│  Port 8000                                                  │
├───────────────┬──────────────────┬──────────────────────────┤
│  PostgreSQL   │  Redis           │  Celery (worker + beat)  │
│  :5432        │  :6379           │  via Redis broker         │
└───────────────┴──────────────────┴──────────────────────────┘
```

**Стек:**
- **Backend:** Python 3.12, FastAPI 0.115, SQLAlchemy 2.0 (async), asyncpg, Alembic, Celery 5.4, Redis
- **Frontend:** React 19, TypeScript, Vite, Ant Design 5, React Router, Zustand, Axios
- **AI:** OpenRouter API → Claude Sonnet / Claude Haiku
- **OCR:** Tesseract (pytesseract + tesseract-ocr-rus)
- **Файлы:** PDF (pdfplumber, reportlab, weasyprint), Excel (openpyxl, xlrd), CSV (pandas), XML (lxml)
- **Инфраструктура:** Docker Compose, Nginx reverse proxy

## 8. ⚠️ Выявленные проблемы и замечания

### 🔴 Критичные

1. **Утечка секретов в `.env.example`** — файл содержит **реальные** API-ключи:
   - `OPENROUTER_API_KEY=sk-or-v1-9a51cf...` 
   - `TELEGRAM_BOT_TOKEN=7897026676:AAF-wx...`
   - `TINKOFF_API_TOKEN=t.Jky4XEOf...`
   - `SBERBANK_CLIENT_SECRET=d\`b<9D[.`
   - **Действие:** немедленно заменить на плейсхолдеры, ротировать скомпрометированные ключи

### 🟡 Предупреждения

2. **Нет `.env` файла в репозитории** (корректно), но `.env.example` должен содержать только шаблоны
3. **Нет миграций Alembic** — папка `alembic/versions/` может быть пустой, нужно сгенерировать initial migration
4. **`integrations/`** — пустой пакет, заглушки для Этапа 2
5. **Тесты** — папка `backend/tests/` существует, но объём покрытия не проверен
6. **Frontend .env** — нет `frontend/.env.example` для `VITE_API_BASE_URL` и т.д.

### 🟢 Положительные моменты

7. **Полная типизация** — Pydantic v2 схемы, TypeScript на фронте
8. **Async everywhere** — asyncpg, async SQLAlchemy, async Alembic env
9. **Корректная структура** — чистое разделение layers (models → schemas → services → endpoints)
10. **Docker prod/dev** — два compose-файла, multi-stage nginx build
11. **AI-агент с инструментами** — полноценная tool-calling архитектура
12. **Celery beat** — автоматические проверки дедлайнов и формирование отчётов

## 9. Рекомендации по следующим шагам

### Немедленно
1. ⛔ **Заменить реальные ключи** в `.env.example` на плейсхолдеры
2. Проверить, что `.env` в `.gitignore` (✅ уже есть)
