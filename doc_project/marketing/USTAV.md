# 📣 Устав отдела маркетинга и продвижения

Единые правила для всей команды. Каждый агент обязан следовать этому документу.

## Бизнес
ИП Нуршинов Р.У. Два направления, два аккаунта МойСклад:
- **Мебель** — токен в env `MOYSKLAD_FURNITURE_API_TOKEN` (658 позиций).
  Поставщики кодируются префиксом в названии: `IMP` = Империал, `AL` = прочие.
- **Бытовая техника (Gambit)** — токен в env `MOYSKLAD_GAMBIT_API_TOKEN` (5081 позиция).
  Категории заданы (productFolder: «LED 32"», «50-55 литров» и т.п.), бренды в названии.

API МойСклада: `https://api.moysklad.ru/api/remap/1.2`, заголовок `Authorization: Bearer <token>`.
Цены в API хранятся в **копейках**.

## Железобетонные правила (нарушать нельзя)
1. **Цены в рекламе не показываем.** Только «АКЦИЯ», «-30%», «последний на складе» и т.п.
2. **Скидка не опускается ниже закупочной цены.** Это проверяет Алия (бухгалтер).
3. **Залежалый товар** = нет продаж более **6 месяцев** + есть остаток.
4. Остатки аккаунта **Gambit не выверены** (давно не было ревизии) → всегда предлагаем
   **несколько кандидатов**, чтобы было из чего выбрать, если товара не окажется в наличии.
5. Кандидаты берём **и из залежалых, и из свежего привоза**.
6. Токены/пароли — **только** в переменных среды / Сетевых секретах. Никогда в чат, код или git.
7. Все файлы-результаты складываем в проект (`doc_project/marketing/output/`). Публикует владелец сам.

## Каналы публикации
MAX, WhatsApp, Telegram, Одноклассники. Формат видео/карточек — **вертикаль 9:16**.
Автопостинг: Telegram (Bot API) → потом OK (OK API). MAX/WhatsApp — вручную владельцем.

## Источники фото
- **Мебель:** гипермаркетмебели.рф, оф. сайт фабрики «Империал», розничный магазин «Шара».
  (Товары `IMP` → приоритетно искать на сайтах Империал/гипермаркетмебели.)
- **Техника:** интернет по «бренд + модель» (бренд и модель есть в названии товара).

## Видео (моушен-дизайн)
- Длительность **40 сек**, вертикаль 9:16, музыку даёт владелец.
- Движок: HTML/CSS/JS-анимация → рендер Playwright (Chromium) покадрово → сборка ffmpeg + музыка.
- Монтаж подгоняется под биты трека. Цены не показываем.

## Утренний ритуал (крон 9:00)
Дамир готовит подборку кандидатов (залежалые + свежий привоз, по 2+ из каждого направления),
владелец выбирает → дальше запускается цепочка: дисконт → фото → карточка → ролик → пост.
