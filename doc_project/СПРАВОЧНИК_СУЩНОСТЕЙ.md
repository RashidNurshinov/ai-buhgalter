## 2. МОДЕЛИ БАЗЫ ДАННЫХ (SQLAlchemy)

> **BaseModel** (`backend/app/models/base.py`): все модели наследуют от `BaseModel`, который добавляет:
> - `id: str` — UUID в виде строки (default: `uuid4().hex`)
> - `created_at: datetime` — с timezone, server_default=`now()`
> - `updated_at: datetime` — с timezone, onupdate=`now()`

### 2.1. Таблица `users` (модель `User`)

**Файл:** `backend/app/models/user.py`

| Поле | Тип в модели | Тип в БД | nullable | Описание |
|---|---|---|---|---|
| `id` | `str` | `String(32)` PK | No | UUID hex (от BaseModel) |
| `email` | `str` | `String(255)`, unique, index | No | Email (логин) |
| `hashed_password` | `str` | `String(255)` | No | Хэш пароля (bcrypt) |
| `full_name` | `str` | `String(255)` | No | ФИО |
| `inn` | `str \| None` | `String(12)` | Yes | ИНН предпринимателя |
| `business_name` | `str \| None` | `String(500)` | Yes | Наименование бизнеса |
| `tax_system` | `TaxSystem` | `Enum(TaxSystem)` | No | Система налогообложения |
| `is_active` | `bool` | `Boolean` | No | Активен ли аккаунт (default=True) |
| `created_at` | `datetime` | `DateTime(tz)` | No | от BaseModel |
| `updated_at` | `datetime` | `DateTime(tz)` | No | от BaseModel |

**Relationships:**
- `settings` → `UserSettings` (uselist=False, back_populates="user")

## 7. ПРАВИЛА ИМЕНОВАНИЯ

### 7.1. Python (backend)
- **Модели:** PascalCase — `BankOperation`, `KudirEntry`, `AgentEvent`
- **Таблицы БД:** snake_case, мн. число — `bank_operations`, `agent_events`
- **Файлы моделей:** snake_case, ед. число — `bank_operation.py`, `agent_event.py`
- **Schemas:** PascalCase + суффикс — `BankOperationResponse`, `AgentChatRequest`
- **URL:** kebab-case — `/api/v1/purchase-book/`
- **Enum-значения:** snake_case — `usn_income_expense`, `event_file_uploaded`
- **Services:** PascalCase + Service — `ClassifierService`, `AIAgentService`
- **Tasks:** prefix `agent_` для агентских, `task_` для обычных — `agent_daily_check`, `task_process_uploaded_file`

### 7.2. TypeScript (frontend)
- **Компоненты:** PascalCase — `DocumentTable.tsx`
- **API-модули:** camelCase — `documentsApi`, `agentApi`
- **Hooks:** `use` prefix — `useAuth`
- **Stores:** camelCase + Store — `authStore`

### 7.3. FK-поля
- Паттерн: `linked_{entity}_id` для связей между сущностями
- Прямые владельцы: `user_id`, `bank_account_id`, `counterparty_id`, `document_id`, `event_id`
