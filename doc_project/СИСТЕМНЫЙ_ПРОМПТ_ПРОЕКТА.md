### Правила написания кода

#### Модели (SQLAlchemy)
- Наследуй от `BaseModel` (`app.models.base`) — он даёт `id` (str UUID hex), `created_at`, `updated_at`
- ID — строка 32 символа (uuid4().hex), НЕ integer
- Все FK: `ForeignKey("table_name.id", ondelete="CASCADE"|"SET NULL")`
- Enum-поля: `Enum(EnumClass, name="enum_name_enum")` — суффикс `_enum` в имени
- JSONB для произвольных данных: `from sqlalchemy.dialects.postgresql import JSONB`
- Decimal для денег: `Numeric(15, 2)`, для ставок: `Numeric(5, 2)`

#### Schemas (Pydantic v2)
- Наследуй от `BaseSchema` (`app.schemas.base`) с `model_config = ConfigDict(from_attributes=True)`
- Суффиксы: `Create`, `Update`, `Response` — например `DocumentCreate`, `DocumentResponse`
- Для Optional полей: `field: str | None = None`
- Для Decimal: используй `Decimal` из стандартной библиотеки

#### API роутеры
- URL-пути в kebab-case: `/api/v1/purchase-book/`, `/api/v1/sales-book/`
- Файлы роутеров в snake_case: `purchase_book.py`
- Все эндпоинты требуют `current_user` через `Depends(get_current_user)`
- Фильтрация данных ВСЕГДА по `user_id` текущего пользователя
- Используй `PaginatedResponse` для списков

#### Сервисы
- Один сервис = один файл в `services/`
- Все методы — async
- Принимают `db: AsyncSession` первым аргументом
- НЕ импортируй модели внутри роутеров напрямую — используй сервисный слой

#### Celery задачи
- Prefix `task_`: `task_process_uploaded_file`, `task_sync_bank_statements`
- Используют синхронную сессию БД (отдельный sessionmaker)

#### Enum-ы
- Все в одном файле: `app/constants/enums.py`
- Наследуют `(str, Enum)` — для JSON-сериализации
- Значения в snake_case: `usn_income_expense`, `manual_upload`

- НДС: 22% (основная), 10% (пониженная), 0% (экспорт). Расчётная: 22/122
- УСН «Доходы минус расходы»: 15% (базовая), 20% (повышенная при превышении лимитов)
- Минимальный налог УСН: 1% от доходов (ст. 346.18 НК РФ)
- Фиксированные взносы ИП: 53 658 ₽ + 1% с доходов свыше 300 000 ₽
- МРОТ 2026: 22 440 ₽
- НДФЛ: 13% (до 5 млн), 15% (свыше 5 млн)
- Страховые взносы за сотрудников: 30% (до предела 2 759 000 ₽), 15.1% (свыше)

### AI-Агент (Agent-First Architecture)
- Центральный ИИ-компонент: `services/ai_agent.py` — AIAgentService
- Инструменты агента: `services/agent_tools.py` — AgentToolsRegistry (tool calling)
- Системный промпт: `prompts/agent_system.py` — AGENT_SYSTEM_PROMPT
- OpenRouter клиент: `services/openrouter_client.py` — с поддержкой tool_choice
- Модели БД: `AgentEvent`, `AgentActionLog`, `AgentConfirmation`
- Enum'ы: `AgentTriggerType`, `AgentEventStatus`, `AgentActionType`, `AgentConfirmationStatus`
- API: `/api/v1/agent/` (chat, command, confirm, events, confirmations, stats)
- Celery-задачи: `tasks/agent_tasks.py` (agent_daily_check, agent_weekly_report, agent_monthly_analysis, agent_check_deadlines, agent_on_file_uploaded)

### Известные подводные камни (pitfalls)

#### 1. Двойная сессия БД (get_db vs get_async_session)
В `core/dependencies.py` есть ДВА генератора сессий: `get_db()` и `get_async_session()`.
Оба создают `AsyncSession`, но могут использовать разные `sessionmaker`.
**Правило:** В роутерах используй ТОЛЬКО `get_db` через `Depends(get_db)`.
Если нужна сессия вне request-контекста (Celery, background task) — создавай через `async_session_maker()`.

#### 2. Frontend API — один файл endpoints.ts
Все API-функции (`authApi`, `filesApi`, `agentApi`) находятся в ОДНОМ файле `frontend/src/api/endpoints.ts`.
Типы/интерфейсы — в `frontend/src/types/index.ts`. НЕ создавай отдельные файлы `auth.ts`, `agent.ts` и т.д.

#### 3. Nginx в prod — статика, не proxy
В production nginx раздаёт собранный SPA из `/usr/share/nginx/html` (multi-stage build).
Контейнер `frontend` (dev-сервер Vite на порту 3000) в prod НЕ используется.
nginx.conf проксирует только `/api/` и `/ws/` на backend, остальное — `try_files $uri /index.html`.

#### 4. Docker rebuild при изменении файлов
Dockerfile использует `COPY`, поэтому `docker compose restart` НЕ подхватывает изменения файлов.
Нужен `docker compose build <service>` + `docker compose up -d <service>`.

### Чего НЕ делать
- НЕ генерируй IP-адреса, пароли, API-ключи из памяти — спроси
- НЕ создавай новые enum-значения без добавления в enums.py
- НЕ меняй структуру BaseModel без обновления СПРАВОЧНИКА
- НЕ используй integer ID — только строковые UUID hex
- НЕ пиши SQL напрямую — используй SQLAlchemy ORM
- НЕ создавай синхронные эндпоинты — всё async

5. Автоматическое соблюдение архитектуры (модель → сервис → роутер)
